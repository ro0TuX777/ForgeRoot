# Phase 9 Claim Boundary

## 1. Safe Claims

| Safe Claim | Notes |
|---|---|
| ForgeLedger provides governance evidence support for agentic systems. | Accurate. |
| ForgeLedger can produce tamper-evident evidence packages. | Accurate when chain/checkpoint/package verification passes. |
| ForgeLedger supports control mapping and audit preparation. | Accurate with mapping governance caveat. |
| ForgeLedger can help demonstrate policy-governed AI workflow behavior. | Accurate for captured or representative workflows. |
| ForgeLedger is pilot-ready and production-architecture-ready. | Accurate after Phase 8/9, pending deployment hardening. |

## 2. Unsafe Claims

| Unsafe Claim | Why Unsafe |
|---|---|
| ForgeLedger makes you SOC 2 compliant. | Compliance requires qualified assessment of organization and deployment. |
| ForgeLedger certifies NZISM compliance. | Software evidence is not certification. |
| ForgeLedger is production WORM by default. | Local WORM is a simulation unless real object-lock storage is deployed. |
| ForgeLedger provides asymmetric non-repudiation. | Current model is HMAC-SHA256 shared-secret authentication. |
| ForgeLedger prevents all tampering. | It detects many tamper classes but cannot prevent every compromise. |
| ForgeLedger has live integration with every subsystem unless proven. | Current Phase 8g fixtures are representative unless real capture is added. |
| ForgeLedger replaces auditors or compliance professionals. | Human review remains required. |

## 3. Required Disclaimer

ForgeLedger provides evidence support only. It does not certify compliance. Formal compliance determinations require qualified review against the applicable framework, deployment environment, and organizational controls.

## 4. Customer-Facing Short Description

ForgeLedger records governance evidence for agentic AI workflows and can produce tamper-evident, encrypted evidence packages for audit preparation. It provides evidence support only and does not certify compliance.

## 5. Technical-Facing Short Description

ForgeLedger is a governed event ledger with ingest-time redaction, hash-chain integrity, HMAC-SHA256 authentication, checkpoints, anchor abstractions, read auditing, retention lifecycle planning, and evidence package export.

## 6. Sales-Facing Caution Language

Do not claim ForgeLedger makes a customer compliant. Position it as an evidence-support and audit-preparation system. Claims must distinguish local pilot simulations from production infrastructure controls.
